### Title: A Scheduling and Duty Management System with AI Application in Absence Handling

Short Description: The A Scheduling and Duty Management System with AI Application in Absence Handling is a system developed for Kaizen Security Agency Corp. to improve the scheduling and management of security personnel. It allows administrators, head guards, and security personnel to manage bi-weekly duty schedules, monitor attendance, and view duty assignments. It also provides AI-assisted recommendations for selecting available relievers when security personnel are absent.

## System Requirements & Prerequisites

Before installing and running the application, ensure that your device meets the following requirements.

### Windows Application (.exe)

- A Windows computer.
- A compatible Windows operating system.
- An active internet connection.
- Sufficient storage space for the application installation.
- Permission to install and run the application on the device.

### Android Application (.apk)

- An Android smartphone or tablet.
- A compatible Android operating system.
- An active internet connection.
- Sufficient storage space for the application installation.
- Permission to install applications from the downloaded APK file.

### Additional Requirements

- Internet access is required to communicate with the hosted backend services.
- The backend and database are hosted online, so no local server or database installation is necessary.
- Allow at least **1 minute** for the application to refresh and establish a connection with the backend server hosted on Render.

 ## Installation & Setup Instructions

Follow the instructions below to install and run the application on your device.

### 1. Windows Application (.exe)

1. Download the Windows application installer (`.exe`) from the provided release or repository files.
2. Locate the downloaded installer on your computer.
3. If Windows displays a security warning, select **More Info** and then **Run Anyway**, if you trust the source of the application.
4. Follow the installation instructions provided by the installer.
5. Once the installation is complete, open the application.
6. Wait at least **1 minute** for the application to refresh and establish a connection with the backend server hosted on Render.
7. After refreshing, the application should be ready to use.

### 2. Android Application (.apk)

1. Download the Android application package (`.apk`) from the provided release or repository files.
2. Locate the downloaded APK file on your Android device.
3. If prompted, allow your device to install applications from this source. You may need to enable **Install Unknown Apps** in your device settings.
4. Proceed with the installation.
5. Once installed, open the application.
6. Wait at least **1 minute** for the application to refresh and establish a connection with the backend server hosted on Render.
7. After refreshing, the application should be ready to use.

### 3. Important Reminders

- An active internet connection is required to access the application's backend services.
- The application may take at least **1 minute** to refresh because the backend is hosted on Render.
- If the application does not load immediately, wait for the refresh process to complete before attempting to use it.
- Make sure to download the correct application version for your device (Windows `.exe` or Android `.apk`).
